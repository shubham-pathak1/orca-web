# Orca Website

The landing page for Orca, a minimal native music player for Windows built with Rust and Slint.

Live at [orca-music.vercel.app](https://orca-music.vercel.app).

## Tech Stack

The desktop player uses Rust and Slint. This website is built with:
- **Svelte** (Framework)
- **TypeScript** (Language)
- **Vite** (Build tool)
- **Vanilla CSS** (Styles)

## Getting Started

### Prerequisites

You will need [Bun](https://bun.sh/) (recommended) or [Node.js](https://nodejs.org/) installed.

### Development

Install the dependencies:

```bash
bun install
# or npm install
```

Start the development server:

```bash
bun run dev
# or npm run dev
```

### Build

Build the static site for production:

```bash
bun run build
# or npm run build
```

## Deployment

The project is automatically deployed to Vercel upon pushing to the `main` branch.
